## 1. التعهد الصارم بحماية الخصوصية (Zero-Leakage Privacy Policy)
1. **معالجة محلية بالكامل (100% Local In-Browser Processing)**: جميع ملفات `XLSX` و`CSV` التي يقوم المستخدم بفتحها أو تحريرها تتم قراءتها وتفكيكها ومعالجتها داخل ذاكرة متصفح المستخدم مباشرة (Client Memory) دون إرسالها إلى أي خوادم سحابية.
2. **استقلالية محرك الذكاء الاصطناعي**: محرك التدقيق وفحص التكرارات وتحليل الصيغ والاستعلامات الرياضية يعمل بنسبة 100% بدون اتصال بالإنترنت (Offline Mode).
3. **التحكم بالاستدعاءات الخارجية**: أي استدعاء اختياري لنموذج Gemini يجري فقط عند طلب المستخدم الصريح لشرح أو تحليل متقدم، مع إرسال مقتطفات مجهولة المصدر للمخطط فقط بعد موافقة واضحة.

## 2. إجراءات الأمان البرمجي وتفادي الثغرات

### أ. الحماية من ثغرات حقن صيغ CSV (CSV Formula Injection / DDE Mitigation)
عند تصدير البيانات إلى ملف CSV أو استيرادها:
- إذا كانت قيمة الخلية النصية تبدأ بأحد الرموز الحسابية الخطرة: `=`, `+`, `-`, `@`, `\t`, `\r`، يضيف المحرك فاصلة علوية أحادية بادئة (`'`) تلقائياً قبل الرمز عند التصدير لمنع البرامج الخارجية (مثل Excel أو Calc) من تنفيذ أوامر نظام تشغيل ضارة (DDE Execution) في بيئة المستخدم.

### ب. منع تشغيل الماكرو والأكواد غير الموثوقة (No Macro / VBA Execution)
- لا ينفذ التطبيق أي كود VBA أو Macro أو VBScript مدمج في ملفات المصنفات المستوردة.
- يتم تجاهل عناصر ActiveX البرمجية منعاً لاختراق بيئة العميل.

### ج. حماية محرك الصيغ من `eval`
- محرك الصيغ مكتوب بمحلل تعبيرات شجري صارم (Recursive-descent AST Parser) ولا يستخدم دالة `eval()` أو `new Function()` مطلقاً، مما يقضي تماماً على ثغرات Remote Code Execution داخل التطبيق.

### د. حماية الذاكرة من الإغراق (DoS / Memory Exhaustion Protection)
- تحديد سقف آمن لحجم الملفات المدخلة في الذاكرة لتجنب استهلاك موارد جهاز المستخدم أو تجميد المتصفح.
- تقنية العرض الافتراضي (DOM Virtualization) تمنع المتصفح من إنشاء ملايين عقد DOM للخلايا الكبيرة.

## 3. سجل العمليات والتدقيق غير القابل للتلاعب (Immutable Audit Trail)
- يتم تسجيل كل تعديل أو معالجة أو حذف في سجل تدقيق محلي (Audit History Log) يتضمن:
  - توقيت العملية (Timestamp).
  - نوع العملية (تعديل خلية، دمج، إزالة تكرار، تصحيح محارف).
  - الخلية والورقة المتأثرة.
  - القيمة السابقة والقيمة الجديدة.
  - هوية الإجراء (مستخدم يدوي، أو معالجة مقترحة من الوكيل).
- جميع العمليات قابلة للتراجع الكامل (Full Undo/Redo Support).
