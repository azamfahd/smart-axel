# مواصفات محرك الصيغ والحسابات (FORMULA_ENGINE.md)
## DataAudit AI Pro — Deterministic Formula Engine Specification

---

## 1. المبادئ التصميمية الأساسية
1. **أمان تام بدون `eval`**: لا يُستخدم `eval` أو تشغيل نصوص برمجية بشكل مباشر تحت أي ظرف.
2. **تحليل نحوي صارم (Strict Recursive-Descent AST)**: تحويل نص الصيغة (مثل `=IF(SUM(A1:A5)>100, "High", "Normal")`) إلى شجرة تعبيرات نحوية (Abstract Syntax Tree).
3. **مخطط التبعيات الدوري وحماية الدورة (Recalculation DAG & Cycle Detection)**: بناء Directed Acyclic Graph لتبعيات الخلايا لتحديث الخلايا المتأثرة فقط عند التعديل، مع اكتشاف فوري ومباشر للمراجع الدائرية وإرجاع خطأ `#CYCLE!`.
4. **تطابق سلوكيات Excel في تحويل الأنواع (Type Coercion)**: التعامل الدقيق مع تحويل النصوص الرقمية إلى أرقام، والقيم المنطقية، ومعالجة الخلايا الفارغة كأصفار في العمليات الحسابية.

## 2. مراحل معالجة الصيغة (Formula Pipeline)

```
[ Formula String ]  -->  "=SUM(A1:B2) * 1.15"
         │
         ▼
[ 1. Tokenizer / Lexer ]
- تصنيف الرموز: FUNCTION("SUM"), OPEN_PAREN, REF("A1"), COLON, REF("B2"), CLOSE_PAREN, OP("*"), NUMBER(1.15)
         │
         ▼
[ 2. AST Parser ]
- بناء شجرة العمليات مع مراعاة أولوية المعاملات الحسابية (PEMDAS)
- BinaryOp( *, FunctionCall("SUM", Range("A1", "B2")), Literal(1.15) )
         │
         ▼
[ 3. Reference Extractor ]
- استخراج قائمة الخلايا المطلوبة: { A1, A2, B1, B2 }
- إضافة حواف في رسم التبعيات: A1 -> CellX, A2 -> CellX, B1 -> CellX, B2 -> CellX
         │
         ▼
[ 4. Dependency DAG & Cycle Check ]
- التحقق من عدم وجود مسار يعود لنفس الخلية (Tarjan's or DFS Cycle Detection)
         │
         ▼
[ 5. Evaluator ]
- تقييم الشجرة حسابياً واسترجاع القيم من ذاكرة أوراق العمل
- إرجاع القيمة المحسوبة ونوعها (Number, String, Boolean, Error)
```

## 3. قائمة الدوال المدعومة تفصيلياً (Supported Functions Library)

### أ. دوال المجموع والإحصاء
- **`SUM(range1, [range2, ...])`**: جمع كل القيم الرقمية مع تجاهل النصوص والخلايا الفارغة.
- **`AVERAGE(range1, ...)`**: حساب المتوسط الحسابي للقيم الرقمية.
- **`MIN(range1, ...)`**: استخراج أصغر قيمة.
- **`MAX(range1, ...)`**: استخراج أكبر قيمة.
- **`COUNT(range1, ...)`**: عد الخلايا المحتوية على أرقام فقط.
- **`COUNTA(range1, ...)`**: عد الخلايا غير الفارغة (أرقام، نصوص، قيم منطقية).
- **`SUMIF(range, criteria, [sum_range])`**: جمع الخلايا التي تحقق شرطاً معيناً (مثل `">1000"` أو `"=مكتمل"`).
- **`COUNTIF(range, criteria)`**: عد الخلايا التي تحقق شرطاً محدداً.
- **`SUMIFS(sum_range, criteria_range1, criteria1, ...)`**: الجمع بشرط متعدد.
- **`COUNTIFS(criteria_range1, criteria1, ...)`**: العد بشرط متعدد.

### ب. الدوال المنطقية والشرطية
- **`IF(condition, value_if_true, [value_if_false])`**: التحقق من شرط وإرجاع قيمة بناءً على صحته.
- **`AND(logical1, [logical2, ...])`**: إرجاع TRUE إذا كانت كل المعاملات صحيحة.
- **`OR(logical1, [logical2, ...])`**: إرجاع TRUE إذا كان أحد المعاملات صحيحاً.
- **`NOT(logical)`**: عكس القيمة المنطقية.
- **`IFERROR(value, value_if_error)`**: التعامل مع أخطاء الحساب واستبدالها بقيمة بديلة نظيفة.

### ج. دوال البحث والمراجع
- **`VLOOKUP(lookup_value, table_array, col_index, [range_lookup])`**: البحث العمودي ومطابقة المفاتيح.
- **`XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found])`**: البحث المرن في كلا الاتجاهين.
- **`INDEX(array, row_num, [col_num])`**: استرجاع قيمة الخلية في تقاطع صف وعمود محددين.
- **`MATCH(lookup_value, lookup_array, [match_type])`**: استرجاع موضع القيمة داخل النطاق.

### د. الدوال الحسابية والتقريب
- **`ROUND(number, num_digits)`**: تقريب الرقم لعدد محدد من المنازل العشرية.
- **`ROUNDUP(number, num_digits)`**: تقريب لأعلى.
- **`ROUNDDOWN(number, num_digits)`**: تقريب لأسفل.
- **`ABS(number)`**: القيمة المطلقة.
- **`INT(number)`**: استخراج الجزء الصحيح للرقم.
- **`MOD(number, divisor)`**: باقي القسمة.

### هـ. دوال النصوص ومعالجة اللغة العربية
- **`CONCAT(text1, [text2, ...])`** أو استخدام المعامل `&`: دمج السلاسل النصية.
- **`TRIM(text)`**: إزالة المسافات البادئة واللاحقة والمضاعفة.
- **`LEN(text)`**: حساب طول النص (مع دعم اليونيكود بدقة).
- **`LEFT(text, [num_chars])`**: استخراج المحارف من بداية النص.
- **`RIGHT(text, [num_chars])`**: استخراج المحارف من نهاية النص.
- **`MID(text, start_num, num_chars)`**: استخراج مقطع من وسط النص.
- **`UPPER(text)` / `LOWER(text)`**: تحويل حالة الأحرف الإنجليزية.

### و. دوال التاريخ والوقت
- **`TODAY()`**: تاريخ اليوم الحالي بصيغة قياسية.
- **`NOW()`**: التاريخ والوقت الحالي.
- **`DATE(year, month, day)`**: بناء قيمة تاريخ صالحة.
- **`YEAR(date_serial)`**: استخراج السنة.
- **`MONTH(date_serial)`**: استخراج الشهر (1-12).
- **`DAY(date_serial)`**: استخراج اليوم في الشهر (1-31).

## 4. نظام رموز الأخطاء القياسي (Error Codes)
- **`#DIV/0!`**: محاولة القسمة على صفر.
- **`#VALUE!`**: نوع معامل غير صالح (مثل جمع رقم مع نص غير رقمي).
- **`#REF!`**: مرجع خلية غير صالح أو تم حذفه.
- **`#NAME?`**: اسم دالة غير معروف أو رمز غير معرف.
- **`#N/A!`**: قيمة غير متوفرة في دوال البحث مثل VLOOKUP.
- **`#CYCLE!`**: مرجع دائري تم اكتشافه لمنع تجميد البرنامج.
- **`#NUM!`**: خطأ في القيمة الرقمية المدخلة للدالة.
