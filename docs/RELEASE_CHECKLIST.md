## 1. بوابات الاعتماد الإلزامية (Acceptance Criteria Gates)
وفقاً للقسم الثالث والعشرين من مواصفات المشروع، لا يُعتبر البرنامج جاهزاً للإطلاق ما لم تُستوفَ الشروط الـ 17 التالية بالكامل:

| # | معيار الاعتماد (Gate Requirement) | حالة التحقق | ملاحظات المهندس |
| :---: | :--- | :---: | :--- |
| **1** | الواجهة الأساسية وشريط Ribbon تعمل بسلاسة وبشكل تفاعلي كامل. | معتمد | شريط الأدوات بتبويباته العشرة فعال ومرتبط بوظائف حقيقية. |
| **2** | شبكة الخلايا قابلة للتحرير والتنقل والتحديد بكفاءة عالية. | معتمد | دعم التحرير المباشر ومن شريط الصيغ ومقبض السحب. |
| **3** | العمليات الحسابية والصيغ المدعومة دقيقة وتطابق نتائج Excel. | معتمد | أكثر من 30 دالة قياسية تعمل بنجاح بدون `eval`. |
| **4** | استيراد وتصدير ملفات XLSX وCSV مختبر دون فقدان بيانات. | معتمد | الحفاظ على القيم والتنسيقات والصيغ في ملفات حقيقية. |
| **5** | نتائج محرك التدقيق قابلة للتحقق وموثقة بالأدلة والخلايا. | معتمد | ربط كل ملاحظة باسم الخلية والصف وسبب الاشتباه. |
| **6** | وكيل الذكاء الاصطناعي ينفذ استعلامات فعلية على البيانات الحقيقية. | معتمد | استجابة فورية للأوامر العربية واستخراج المجاميع والتكرارات. |
| **7** | جميع عمليات المعالجة المقترحة تخضع للمراجعة وقابلة للتراجع (Undo). | معتمد | بطاقات المعالجة تتطلب موافقة صريحة وسجل تعديل كامل. |
| **8** | العمل المحلي دون اتصال بالإنترنت (Offline Mode) يعمل بنسبة 100%. | معتمد | استقلالية تامة لمحركات البيانات والتدقيق والصيغ. |
| **9** | تجربة Windows المكتبية (الفأرة، لوحة المفاتيح، القوائم) مكتملة. | معتمد | دعم اختصارات لوحة المفاتيح وقوائم النقر الأيمن. |
| **10** | تجربة Android للأجهزة اللوحية والمحمولة متوافقة مع اللمس. | معتمد | واجهة متكيفة، شريط أوراق عمل سهل الوصول، وأزرار واضحة. |
| **11** | مصفوفة ميزات Excel المدعومة موثقة تفصيلياً وبدقة. | معتمد | مسجلة في `EXCEL_COMPATIBILITY_MATRIX.md`. |
| **12** | الميزات غير المدعومة (مثل ماكرو VBA) موضحة صراحة وبشفافية. | معتمد | مسجلة في `KNOWN_LIMITATIONS.md`. |
| **13** | خلو الواجهة تماماً من أي أزرار رئيسية وهمية أو صور ثابتة. | معتمد | كل عنصر تحكم مربوط بوظيفة برمجية حقيقية. |
| **14** | نتائج الاختبارات الفعلية محفوظة ومسجلة في الوثائق. | معتمد | موثقة في `TEST_RESULTS.md`. |
| **15** | المشكلات والقيود المعروفة موثقة بوضوح تام للمستخدم. | معتمد | موثقة في `KNOWN_LIMITATIONS.md`. |
| **16** | نظام إدارة النسخ الاحتياطية والاستعادة المحلي يعمل ومختبر. | معتمد | دعم حفظ نسخ العمل واستعادتها من الذاكرة المحلية. |
| **17** | سلامة البيانات محفوظة ومحمية من التلف أثناء جميع العمليات. | معتمد | فصل القيمة الأصلية عن التنسيق وحماية صيغ CSV. |

## 2. إجراءات ما قبل الإصدار النهائي (Pre-Flight Steps)
1. تشغيل فحص البناء الأوتوماتيكي وتأكيد عدم وجود أخطاء في الـ TypeScript (`npm run lint` / `compile_applet`).
2. التأكد من تطابق عناوين الصفحة وبيانات `metadata.json` وملاءمتها للمعاينة والإنتاج.
3. التأكد من حفظ نموذج المصنف التجريبي للتدقيق المحاسبي المدمج لتسهيل تجربة العميل فور التشغيل.
