## DataAudit Agent — Architecture, NLP Engine & Safe Execution Design

## 1. فلسفة عمل الوكيل ومبدأ "المصدر الحقيقي للبيانات"
وكيل **DataAudit Agent** مصمم بمبدأ صارم:
> **الذكاء الاصطناعي ليس المصدر الوحيد للحقيقة في الحسابات أو التدقيق.**

إذا سأل المستخدم: *"ما هو إجمالي الرواتب؟"*، فإن الوكيل لا "يخمن" الرقم من نموذج لغوي، بل يستخرج نية المستخدم (Intent: SUM)، ويحدد العمود المستهدف (Column: Salary)، ثم يوجه الأمر مباشرة إلى **محرك البيانات ومحرك الصيغ المحلي** لتنفيذ الحساب الدقيق 100% وإرجاع النتيجة الرقمية الموثوقة مع تحديد الخلايا المرتبطة.

## 3. محرك معالجة اللغة الطبيعية المحلي (Local Arabic & English NLP)
يعمل المحرك المحلي عبر:
1. **تطبيع النص العربي (Arabic Text Normalization)**:
   - توحيد الهمزات: (أ، إ، آ) -> ا
   - توحيد الياء والألف المقصورة: (ى) -> ي
   - توحيد التاء المربوطة والهاء: (ة) -> ه
   - إزالة علامات التشكيل والتطويل (ـ).
2. **قاموس المرادفات والمصطلحات المحاسبية والتدقيقية**:
   - `SUM`: "احسب إجمالي", "مجموع", "كم حاصل جمع", "total", "sum".
   - `AVERAGE`: "متوسط", "معدل", "average", "mean".
   - `DUPLICATES`: "تكرارات", "مكرر", "duplicates", "ابحث عن التكرار".
   - `AUDIT_ALL`: "افحص الملف", "تدقيق شامل", "check errors", "audit sheet".
   - `OUTLIERS`: "القيم الشاذة", "عمليات غير معتادة", "outliers", "anomalies".
3. **مطابقة أعمدة الجدول التلقائية**:
   - الربط الذكي بين الكلمات المذكورة في السؤال وأسماء الأعمدة الفعلية (مثل: "المصروفات" -> عمود "Expenses" أو "المصروف").

## 4. ضمانات الأمان والخصوصية في وكيل الذكاء الاصطناعي
1. **منع تنفيذ أوامر النظام (No System Command Execution)**: لا يمتلك الوكيل أي صلاحية لتنفيذ أوامر shell أو تعديل ملفات خارج نطاق مساحة عمل ورقة البيانات المفتوحة.
2. **منع التعديل المباشر الصامت**: إذا اقترح الوكيل إزالة سجلات مكررة أو تصحيح أسماء بها مسافات زائدة، يتم إرسال الاقتراح كـ **Remediation Card** تحتوي على جدول الفروقات قبل/بعد، وتتطلب ضغط المستخدم على زر "تطبيق التعديل".
3. **صفر بيانات سحابية للمهام المحلية**: فحص التكرارات، اكتشاف المسافات الخفية، الحسابات الرياضية، وتصفية البيانات تجري بنسبة 100% داخل المتصفح والبيئة المحلية دون أي حركة شبكة خارجية.
